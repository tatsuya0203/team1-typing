# 寿司打風 — ことばのタイピング練習

`index.html` をブラウザーで開いて利用します。ビルドや追加ライブラリは不要です。

## 遊び方

- 開始画面から全10問に挑戦します。時間制限はありません。
- 日本語入力オンのまま遊べます。半角・全角英数、読みのひらがな・カタカナに対応します。
- IME使用時は、漢字に変換せず **かなのままEnterで確定** すると進みます。未確定文字は問題の下に表示します。漢字確定は無採点で、かなでの再入力を案内します。
- 入力欄をクリックする必要はありません。開始・再開時に画面内のIME用編集ターゲットへ自動フォーカスします。問題部分をクリックしてもフォーカスを戻せます。
- プレイ中は説明と成績一覧を隠し、問題・次の文字・皿数を表示します。
- Escまたは一時停止ボタンで中断できます。確定済みの進捗を保持し、未確定の変換は取り消します。変換中のEscはIME本来の取消操作です。
- 別タブへ移動した場合は自動停止します。戻ってから明示的に再開してください。
- 全10問を終えると成績を表示し、再挑戦できます。
- Tab移動やブラウザーショートカットは維持します。ボタン上のSpace/Enterはボタン操作になります。

## 入力・採点仕様

- 表示するローマ字は訓令式ベース（ち=ti、つ=tu、ふ=hu、じょ=zyo）。
- ローマ字で「ん」を打つ場合は必ず `nn`。ごめんなさいは `gomennnasai`。かなの「ん」を確定しても同じ進捗へ変換します。
- 長音は読み仮名の母音を残し、「ー」は `-`。助詞は「は=ha」「を=wo」です。
- 全角英数・英大文字を正規化し、カタカナをひらがなにそろえて照合します。
- かなは各拍とローマ字の位置対応で照合します。「じ」「ょ」のような分割確定や、ローマ字の途中からかなへの切替に対応します。
- `QUESTIONS` の読みからローマ字を生成し、問題ごとの方式の混在を防ぎます。
- 正解文字数はローマ字換算。誤入力は英数の1文字または確定かな1文字ごとに1回です。正答率はこの正解文字数とミス回数から算出します。
- 未確定文字・漢字変換・修飾キー・長押しは採点しません。貼り付けは無効です。
- IMEの確定時に発生するcompositionendと後続inputを重複採点しません。

## 見た目

寿司打の公開画面資料を参考に、淡い緑の背景・木枠・黒い大きなタイトル・木製メニュー・寿司のレーン・黒い問題帯・湯呑み・醤油皿・積み皿・紙状の結果画面をCSSで構成しています。ゲームを中央のコンパクトな枠に収め、表示密度と配置を参考画面に近づけています。公式画像・ロゴ画像やゲーム資産は使っていません。

開始画面の「遊び方」「設定」を開けます。設定ではふりがな・ローマ字の表示を切り替えます。残り皿数と完食メーターは実際の完了数に連動します。時間制限なしの全10問という練習仕様は維持しています。

## 検証

```sh
node --check kadai6.js
node --test tests/typing.test.js
```

Node.js標準テストで全問題のローマ字、かな対応位置、ページ入力、画面遷移、中断・再開、模擬IMEイベント・二重採点防止を検証します。

実ブラウザー・各OSのIMEによる候補ウィンドウやイベント順序は、この環境では未検証です。
